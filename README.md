# Insurance Cost Prediction using Regression

## Project Overview

This project predicts insurance charges using regression techniques and machine learning. The project includes data cleaning, exploratory data analysis (EDA), preprocessing, model building, hyperparameter tuning, and evaluation.

## Objective

Build regression models to understand factors affecting insurance charges and generate predictions for unseen data.

## Dataset Features

* Age
* Gender
* BMI
* Number of Children
* Smoking Status
* Region
* Insurance Charges
